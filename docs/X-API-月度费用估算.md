# X API 月度费用估算

按 30 个 KOL、每天抓一次算:

| 计费项 | 单价 | 每天用量 | 每月用量(30 天) | 月费 |
|---|---|---|---|---|
| 文章:阅读(抓推文) | $0.005/条 | 30 人 × 最多 5 条 = 150 条 | 4,500 条 | $22.50 |
| 用户:阅读(用户名查 ID) | $0.010/个 | 30 个 | 900 个 | $9.00 |
| | | | **合计** | **≈ $31.50** |

## 实际会比这个低

不是每个 KOL 每天都发推,24 小时窗口内多数人凑不满 5 条。按平均 3 条算:

- 推文:30 × 3 × 30 = 2,700 条 × $0.005 = **$13.50**
- 用户查 ID:900 × $0.010 = **$9.00**
- **≈ $23/月**

## 还能再砍

用户名→ID 是固定映射,缓存一次就行,不用每天查。改一行代码把 ID 存进 `state-feed.json`,之后这笔归零:

- 推文 $13.50 + 用户 $0 = **≈ $15/月**

## 结论

| 情形 | X 月费 |
|---|---|
| 最坏(每人每天 5 条) | ~$32 |
| 实际(平均 3 条) | ~$23 |
| 实际 + 缓存 user ID | **~$15** |

**大概 $15 ~ 30/月,实际落在 $20 左右。** 没有其他 X 计费项了(引用推文、互动数据这些 `generate-feed.js` 都没单独调,不另收费)。
