# 飞书推送配置说明（Phase 3 收尾）

本文档说明 Z.ai MKT Brief 推送到飞书群前还需要的两步配置。

## 当前状态（2026-08-11）

- ✅ Cron job 已注册：`Z.ai MKT Brief`（id `cf053079-0d48-4df4-831a-1b7d8df32898`）
  - 每天 09:30 Asia/Shanghai 触发
  - 推送目标：飞书群 `oc_b85c375a9a9cc0ae9e5b160588c1972b`
  - `--best-effort-deliver`：飞书未配好时不会让 job 失败

## 第 1 步：配置飞书 channel（需要飞书自建应用凭证）

OpenClaw 推送到飞书需要一个飞书自建应用（机器人），把它加进目标群。

### 1.1 在飞书开放平台创建自建应用
1. 打开 https://open.feishu.cn → 创建企业自建应用
2. 拿到 **App ID**（`cli_xxx`）和 **App Secret**
3. 应用能力 → 开启「机器人」
4. 权限管理 → 至少开通：
   - `im:message:send_as_bot`（以机器人身份发消息）
   - `im:message`（读消息，可选）
   - `im:chat`（群信息，可选）
5. 事件订阅 → 选 **长连接（WebSocket）** 方式
6. 应用发布 → 版本管理与发布 → 管理员审批通过

### 1.2 把机器人加进目标群
在飞书群 `oc_b85c375a9a9cc0ae9e5b160588c1972b` 里 → 设置 → 群机器人 → 添加上面创建的机器人。

### 1.3 在 OpenClaw 里配置 channel
```bash
openclaw channels login --channel feishu
# 选 Manual setup，粘贴 App ID 和 App Secret
openclaw gateway restart
```
或直接编辑 OpenClaw 配置文件（JSON5）：
```json5
{
  channels: {
    feishu: {
      appId: "cli_xxx",
      appSecret: "xxx",
      domain: "feishu",
      connectionMode: "websocket",
      groupPolicy: "allowlist",
      groupAllowFrom: ["oc_b85c375a9a9cc0ae9e5b160588c1972b"]
    }
  }
}
```

### 1.4 验证
```bash
openclaw channels list       # Feishu 应显示 configured / enabled
openclaw channels status --probe
```
